## Deskripsi Game
Ghost Run adalah game 2D bertema horor yang dikembangkan menggunakan Unity dan bahasa pemrograman C#. Game ini menampilkan suasana hutan gelap dengan karakter skeleton sebagai elemen utama dalam permainan.

Game ini memiliki tampilan menu utama bernuansa horor dengan beberapa tombol seperti Start, Level, dan About.

---

## Tujuan Project
Project ini dibuat untuk melatih kemampuan dalam membuat game 2D menggunakan Unity, mulai dari pembuatan tampilan menu, penggunaan asset sprite, pengaturan scene, hingga penerapan script menggunakan C#.

---

## Fitur Game
- Menu utama dengan tema horor
- Tombol Start untuk memulai permainan
- Tombol Level untuk memilih level
- Tombol About untuk melihat informasi game
- Background hutan menyeramkan
- Karakter skeleton
- Asset 2D
- Sistem perpindahan scene

---

## Cara Bermain
1. Buka game Ghost Run.
2. Klik tombol Start untuk memulai permainan.
3. Kendalikan karakter sesuai instruksi dalam game.
4. Hindari rintangan yang ada.
5. Selesaikan level untuk melanjutkan permainan.

---

## Teknologi yang Digunakan
- Unity 6
- C#
- Visual Studio Code
- 2D Sprite Renderer
- Universal Render Pipeline 2D

---

## Cara Menjalankan Project
1. Download atau clone project ini.
2. Buka Unity Hub.
3. Klik Open Project.
4. Pilih folder project Ghost Run.
5. Tunggu Unity memuat semua asset.
6. Buka scene utama.
7. Klik tombol Play untuk menjalankan game.
